# 12-month backend transition goal

## Main goal

За 12 месяцев я хочу перейти из текущей профессии 1С разработчика в международную Java backend разработку.

## Target role

- Primary target role: Java backend developer, backend developer, Java Spring backend developer, Spring Boot Developer with ERP.
- Alternative roles: Backend Developer, Java Software Engineer, ERP Backend Developer, Integration Developer
- Target level: Junior+ / Middle-

## Target geography / work format

- Countires: Германия, Франция, Италия, Великобритания, Испания
- Remote / relocation / hybrid: Основной вариант с релокацией. Затем, непосредственно в самой стране можно будет попробовать гибрид / удаленку.
- Time zone constraints: Europe/CET-compatible schedule. Relocation is preferred, so long-term timezone constraints should be minimal.

## Target backend stack

### Must-have

- Java: Java21 / Java 25
- Spring Boot: 4.x / 3.x
- SQL/PostgreSQL: 18.x
- Git/Github: commits, branches, push/pull, README, basic pull-request workflow
- Maven: project structure, dependencies, lifecycle, test/package command
- REST API: HTTP basics, controllers, DTOs, validation, error responses
- Docker: containers, Dockerfile basics, Docker Compose for PostgreSQL/services
- Testing: JUnit/Testcontainers

### Nice-to-have later

- Kafka/RabbitMQ:
- Redis:
- Cloud:
- Kubernetes:
- Observability:

## Weekly commitment

- Minimum hours per week: 15
- Realistic hours per week: 20
- Best days for deep work: Вторник, Суббота.
- Days with limited energy/time: Понедельник, Пятница, Воскресенье

## Succes criteria after 12 months

- Github: публичный профиль с понятным README, аккуратная история коммитов, минимум один основной backend-проект и несколько учебных sandbox-проектов.
- Main project: ERP Lite Platform с backend, PostgreSQL, Docker, тестами, README, архитектурными заметками и понятным локальным запуском.
- Java level: минимум уверенный junior. Супер, если junior+ или middle.
- Spring level: Как и в Java, минимум junior, хорошо junior+/middle.
- Interview readiness: Готов к полноценному техническому интервью на английском языке.
Умею объяснить архитектуру решения, варианты, недочеты.
- Job-search readiness: Нашел несколько целевых компаний, которые реально интересны и готовы помочь с релокацией.
Для каждой компании подготовлены хорошие cover letters.
- SQL level: уверенное проектирование таблиц, связи, индексы, базовая оптимизация запросов, transactions, migrations. 

## Non-goals for now

- Python/FastAPI
- Gamedev
- Math/data/AI

## Risks

| Risk | Why it matters | Countermeasure |
|---|---|---|
| Перегореть из-за плотного графика | Могу перестать делать что-либо и забить на обучение. | Режим сна, отдых, разумный сдвиг графика. |
| Плохое расписание | Большая вероятность распыления и как следствие непонимание куда двигаюсь и зачем. | Планировать еженедельное расписание. Не включать в него нецелевые предметы. |
| Не заниматься английским | Сдвинет возможность получения оффера надолго. | Вынести английский в отдельный процесс и отслеживать его вне технического чата. |
