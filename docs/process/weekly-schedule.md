# Weekly technical learning schedule

## Weekly target

- Minimum : 20 часов
- Target: Будем стремиться к 30, если пойдет легко. Если нет, остановимся на 20 - 25.

## Time allocation

| Area | Hours/week | Purpose |
|---|---:|---|
| Теория по Java/backend | 7-8 | Понимать как устроен язык, его ограничения и особенности. |  
| Кодинг практика | 6-7 | Закреплять теорию практикой, чтобы писать код без подсказок. |
| Проектная работа | 5-6 | Конвертировать теорию и практику в портфолио для рынка. |
| SQL / архитектура | 2-3 | Получить навык построения больших и сложных систем. |
| Алгоритмы / практика интервью | 2-3 | Держать в тонусе алгоритмическое мышление чтобы повысить шансы прохождения интервью. |
| Ревью / рефакторинг / заметки | 2 | Уметь быстро разбираться в коде, понимать слабости, вносить точечные исправления без поломки общей архитектуры. |

## Rules 

- Не учимся пассивно без выделения артефактов.
- Каждый теоретический блок тренеруется кодом, проектом; закрепляется заметками, документами.
- Ревью проектов и задач раз в неделю.
- Если пропускаю день, то переношу только самую важную задачу в recovery block, а не перегружаю следующий день полностью.
- Проектная работа имеет приоритет над бесконечной теорией.
